# TEND beta feedback (10 minutes)

Answer in a reply to the invitation mail. Short answers are fine; "I don't know" is a useful answer.

1. Which framework or agent did you connect, and is it something you use for real work?
2. Your times from the measuring table in the integration guide. Where did you get stuck, and for how long?
3. Did you finish without asking anyone? If not, what did you have to ask?
4. Which error message was unclear, and what did you expect it to say?
5. What would you put behind TEND first? Which of your tools would you never connect, and why?
6. Write one rule you would want (in words). Could you express it with TEND's rules? If not, what was missing?
7. Did the approval flow fit how you work (where and how fast you want to decide)?
8. Was anything TEND showed you wrong, confusing, or missing from Activity?
9. Compared with what you use today (nothing, hooks in Claude Code, OpenAI's tool approvals, an AI gateway, something else): better, worse, or
   different, and in what?
10. Would you keep using it after the beta? What would it need to have, and what would you pay for it, if anything?
